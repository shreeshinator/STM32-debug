This is a repo for getting started with advanced debugging with cortex-debug extension which allows you to debug things like registers values etc directly within VSCode as the default CubeIDE extension doesn't allow that much like the true CubeIDE. To get started, ensure that cubemx and openocd are installed, download cubemx from ST's site. Read the guide for downloading openocd in the repo.
